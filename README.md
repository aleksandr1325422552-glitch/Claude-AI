# 🌻 Ферма Чудес

Клон «Весёлой фермы» на [Three.js](https://threejs.org/), где вместо кур и коров
вы разводите **девушек и монстров**: фей, русалок, ведьм, слизней, дракончиков и
грифонов. А ещё скрещиваете их между собой и получаете гибридов.

Вся графика — процедурная: ни одной картинки и ни одной модели извне, всё
собрано из кубов, сфер и конусов прямо в коде. Звук синтезируется через WebAudio.

```bash
npm install
npm run dev      # http://127.0.0.1:5173
```

```bash
npm run build    # статическая сборка в dist/
npm run preview  # посмотреть собранную версию
npm test         # 25 тестов симуляции
npm run bundle   # всё в один HTML-файл: dist/ферма-чудес.html
```

`npm run bundle` встраивает стили и скрипт прямо в разметку, так что внешних
запросов не остаётся вовсе. Получившийся файл (≈660 КБ) можно открыть двойным
щелчком, положить на любой статический хостинг или туда, где сторонние файлы
запрещены политикой безопасности.

## Как играть

Петля та же, что в «Весёлой ферме»: **вода → трава → существа → товар →
мастерская → фургон → монеты**.

| | Действие |
|---|---|
| ⛲ | Кликните **колодец** — вода наберётся в лейку |
| 🌱 | Кликните **сухую грядку** — потратится одна вода, вырастет трава |
| 🧚 | Существа сами приходят есть. Взрослые роняют товар, малыши растут |
| ✨ | Кликните **товар на земле** — он попадёт на склад (полежав, пропадёт) |
| ⚗️ | **Мастерские** сами берут сырьё со склада и выкладывают изделие рядом |
| 🚚 | Кликайте товары на складе, чтобы загрузить **фургон**, и отправляйте его на рынок |
| 🥚 | В **питомнике** два взрослых существа дают яйцо |
| 👹 | **Тёмные твари** топчут траву и воруют товар — бейте их кликами |
| 🪤 | Пойманных продавайте в цирк, кликнув по клетке |

Горячие клавиши: <kbd>Q</kbd> набрать воду, <kbd>W</kbd> полить грядку,
<kbd>E</kbd> отправить фургон, <kbd>B</kbd> рынок, <kbd>N</kbd> питомник,
<kbd>R</kbd> хозяйство, <kbd>Space</kbd> пауза, <kbd>M</kbd> звук,
<kbd>H</kbd> справка. Камера: перетаскивание — сдвиг, колесо/щипок — приближение.

### Гибриды

Скрестите в питомнике **два разных вида** — получится гибрид, который даёт
товары **обоих родителей по очереди** и работает на 15% быстрее. Внешне он
наследует облик «девушки» из пары и черты второго родителя: рога, крылья, хвост
или шляпу. Слизнефея, драконья ведьма, пернатая русалка — всего 15 сочетаний.

### Цепочки производства

```
2 ✨ + 1 🟢  →  ⚗️ Эликсир        2 🦪 + 1 🔶  →  📿 Амулет
1 🧪 + 1 🪶  →  🪄 Оберег         1 ⚗️ + 1 📿  →  💎 Артефакт
```

Рынок «устаёт»: чем больше однотипного товара вы привозите, тем ниже цена
(до 55% базовой). Со временем она восстанавливается — возите разное.

## Кампания

Восемь уровней: от первой феи на заброшенном лугу до большой ярмарки. За каждый
даётся до трёх звёзд — по затраченному времени. Между уровнями открывается лавка
с восемью постоянными улучшениями (колодец, лейка, удобрение, склад, фургон,
клетка, инкубатор, волшебный сачок). Прогресс хранится в `localStorage`.

## Как устроен код

Строгое разделение: симуляция ничего не знает ни о Three.js, ни о DOM — она
отдаёт наружу состояние (для отрисовки) и события (для эффектов и звука).
Поэтому логику можно целиком прогонять в тестах на Node без браузера.

```
src/
├── main.js              связывает всё вместе, игровой цикл, поток уровней
├── core/                шина событий, детерминированный ГПСЧ, сохранения, WebAudio
├── data/                правила игры: виды, товары, рецепты, планировка, уровни, улучшения
├── sim/                 симуляция: Farm, Creature, Pasture, Factory, Truck, Market,
│                        Warehouse, Nursery, Raider — чистый JS без зависимостей
├── view/                Three.js: World (сцена и камера), FarmView (живые объекты),
│   └── models/          Fx (частицы), Picker (клики лучом), процедурные модели
└── ui/                  Hud (панели) и Panels (модальные окна)
tests/                   25 тестов симуляции (node --test)
```

Несколько решений, которые стоит знать при доработке:

- **Фиксированный шаг симуляции** 1/60 с накоплением, не более 8 шагов за кадр:
  на слабой машине игра слегка замедляется, но не «телепортирует» события.
- **Автоподстройка качества**: если кадры стабильно длиннее 38 мс, движок сам
  снижает разрешение, затем упрощает и отключает тени.
- **Склейка статики** (`mergeStatic`): сотни деревьев, цветов и досок забора
  сливаются в десяток мешей — 1500 вызовов отрисовки превращаются в ~250.
- **Приоритет попадания**: луч курсора сначала проверяет живые объекты и только
  потом постройки, иначе крупная «кнопка» постройки перехватывает клики по тому,
  что стоит рядом с ней.
- **Никаких шрифтов в 3D**: иконки состояний рисуются вектором на canvas, а
  товары на земле — настоящие модели, поэтому сцена выглядит одинаково везде.
