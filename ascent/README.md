# Ввысь

Вертикальный платформер-раннер на Three.js. Бесконечная процедурная башня,
снизу поднимается пустота, сверху ждут следующие пояса высоты. Останавливаться
нельзя — можно только выше.

Вся графика и весь звук порождаются кодом: в проекте нет ни одной картинки,
модели или аудиофайла.

## Запуск

```bash
npm install
npm run dev        # http://127.0.0.1:5174
```

Сборка:

```bash
npm run build      # обычная сборка в dist/
npm run bundle     # плюс один самодостаточный файл dist/ввысь.html
npm test           # тесты физики и генератора
```

`dist/ввысь.html` не тянет ничего извне — его можно открыть двойным щелчком
или положить на любой статический хостинг.

## Управление

| Действие | Клавиатура | Геймпад |
| --- | --- | --- |
| Движение | WASD или стрелки | левый стик |
| Прыжок / двойной прыжок | Пробел | A |
| Рывок | Shift | X или триггер |
| Спрыгнуть с площадки | S + Пробел | вниз + A |
| Пауза | Esc | Start |

На телефоне — виртуальный стик слева и кнопки справа.

Двойной прыжок и рывок тратят стамину, обычный прыжок — нет. Стамина
восстанавливается, когда герой стоит; на бегу — вдвое медленнее. Рывок даёт
короткую неуязвимость и убивает врага, в которого попал.

## Как это устроено

```
src/
  core/      математика, генератор случайных чисел, ввод, звук, сохранение, шина событий
  render/    рендерер, палитра, материалы, небо, камера, эффекты
  world/     столкновения, платформы, декор, генератор башни
  game/      игрок, враги, пикапы, пустота, числа баланса
  ui/         HUD и экраны
```

Границы между модулями зафиксированы в [CONTRACTS.md](CONTRACTS.md).

### Палитра ведёт всё оформление

`render/palette.js` хранит шесть поясов высоты — от солнечного «Подножия» до
«Звёздного предела». Цвет неба, тумана, света, камня и акцентов на любой высоте
получается интерполяцией между соседними поясами, поэтому смена биома не
переключается, а перетекает. Все системы берут цвет оттуда — достаточно
поправить один пояс, чтобы перекрасился весь кадр.

### Числа баланса собраны в одном месте

`game/config.js` — гравитация, сила прыжка, стамина, скорость пустоты, плотность
врагов, шаг генерации. Они связаны: генератор считает максимальную дальность
прыжка по тем же числам, что и физика игрока, и ставит платформы внутри неё с
запасом. Поэтому поднять гравитацию, не тронув генератор, нельзя — башня
починится сама.

### Мир строится сегментами

`world/generator.js` держит несколько сегментов выше игрока и пару ниже,
остальное возвращает в пул. Каждый сегмент генерируется собственным потоком
случайных чисел, привязанным к его номеру, — содержимое не зависит от того, в
каком порядке игрок до него добрался, и один сид всегда даёт одну и ту же башню.

### Тун-шейдинг без самописного материала

`render/materials.js` берёт `MeshToonMaterial` и врезает в него подсветку
контура через `onBeforeCompile`. Так остаются бесплатными тени, туман и все
оптимизации Three.js, а картинка получает ободок света по силуэту, который
отделяет фигуры от фона.
